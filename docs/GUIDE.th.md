## 1. ติดตั้ง

ดาวน์โหลดได้จาก[หน้า Releases](https://github.com/Maskbuild/NKW-Mod-Studio/releases) มีให้เลือก 2 แบบ:

| ไฟล์ | เหมาะกับ |
|---|---|
| `NKW-Mod-Studio-Setup-x.y.z.exe` | ติดตั้งแบบปกติ มีทางลัดใน Start menu |
| `NKW-Mod-Studio-x.y.z-win-x64.zip` | แบบพกพา แตกไฟล์ไว้ที่ไหนก็ได้ แล้วเปิด `NKW Mod Studio.exe` |

สิ่งที่ต้องมี: Windows 10/11 64-bit, อินเทอร์เน็ตตอนทดสอบครั้งแรก (ต้องโหลด Java, Gradle และ Minecraft) และพื้นที่ว่างในดิสก์หลาย GB

> ถ้า Windows SmartScreen ขึ้นว่าป้องกันเครื่องไว้ ให้กด **More info → Run anyway** ที่ขึ้นเพราะแอปยังใหม่ Windows เลยยังไม่รู้จัก

ไม่ต้องติดตั้ง Java หรือ Minecraft เอง แอปจะดาวน์โหลดสิ่งที่ต้องใช้ให้ และถามก่อนทุกครั้ง

## 2. สร้างโปรเจกต์แรก

1. ที่หน้า **หน้าแรก** กด **โปรเจกต์ใหม่** หรือเลือกเทมเพลตใน **เริ่มจากเทมเพลต**:
   - **ว่างเปล่า**: ผืนงานเปล่า
   - **ชุดเริ่มต้น**: ไอเทม บล็อก ดาบ และสูตรคราฟ
   - **ชุดเกราะ**: วัสดุเกราะพร้อม 4 ชิ้น
   - **แผ่นเพลง**: เสียงของเราเอง + แผ่นเพลง
   - **Farmer's Delight**: อาหาร + หม้อต้ม + เขียง
2. กรอกข้อมูล:
   - **ชื่อม็อด**: ชื่อที่ผู้เล่นเห็น เช่น `Ruby Mod`
   - **Mod ID**: ชื่อที่ใช้ภายในเกม ใช้ได้เฉพาะตัวพิมพ์เล็ก ตัวเลข และ `_` เช่น `ruby_mod` ถ้าปล่อยม็อดไปแล้วอย่าเปลี่ยน ไม่อย่างนั้นของในเวิลด์จะหาย
   - **ผู้สร้าง**, **คำอธิบาย**, **เวอร์ชัน**
   - **Mod loader และเวอร์ชัน**: ติ๊กทุก loader/เวอร์ชันที่อยากทำม็อดให้ เปลี่ยนทีหลังได้
3. กด **สร้างโปรเจกต์** แล้วเลือกโฟลเดอร์ แอปจะสร้างโฟลเดอร์ชื่อ `<ชื่อ>.nkw`

โปรเจกต์คือโฟลเดอร์ธรรมดา: `project.json` เก็บกราฟโหนด ส่วน `assets/` เก็บรูป โมเดล และเสียง จะเปิดอีกครั้งก็ใช้ **โปรเจกต์ล่าสุด** ที่หน้าแรก หรือกด **เปิดโปรเจกต์** แล้วเลือก `project.json`

โปรเจกต์ **บันทึกอัตโนมัติ** จุดข้างชื่อจะบอกว่ามีอะไรยังไม่ได้บันทึก กด Ctrl+S เพื่อบันทึกทันที แอปยังเก็บไฟล์สำรองไว้ 10 เวอร์ชันด้วย

### สัญญาอนุญาต (License) และเครดิต

คลิกที่ว่างบนผืนงานให้ไม่มีโหนดถูกเลือก แผงขวาจะแสดงตั้งค่าโปรเจกต์ ซึ่งมี:

- **สัญญาอนุญาต (License)**: บอกว่าคนอื่นทำอะไรกับม็อดเราได้บ้าง
  - เลือกแบบที่นิยมได้ (สงวนลิขสิทธิ์ทั้งหมด, MIT, Apache 2.0, GPL 3.0, LGPL 3.0, MPL 2.0, zlib, CC0, CC BY / BY-SA / BY-NC / BY-NC-SA) หรือเลือก **อื่น ๆ** แล้วพิมพ์ชื่อเอง
  - กด **ใส่ข้อความสัญญาอนุญาตฉบับเต็ม** ถ้าอยากให้มีไฟล์ `LICENSE.txt` ใน .jar ถ้าไม่ใส่ จะมีข้อความสั้น ๆ พร้อมลิงก์ไปยังสัญญาอนุญาตแทน (ยกเว้น "สงวนลิขสิทธิ์ทั้งหมด" ที่จะไม่มีไฟล์นี้)
- **เครดิต**: คนที่ทำเท็กซ์เจอร์ โมเดล เสียง ฯลฯ กด **เพิ่มเครดิต** แล้วกรอก:
  - **ชื่อ** (จำเป็น)
  - **ทำอะไร** เช่น "เท็กซ์เจอร์ทับทิม"
  - **ลิงก์** ไปหน้าของเขา ต้องขึ้นต้นด้วย `https://` หรือ `http://` ไม่อย่างนั้นจะไม่ถูกใส่
  - **ผูกกับไฟล์ในโปรเจกต์**: ไฟล์ที่เขาทำ (ไม่บังคับ) เลือกเป็น **โฟลเดอร์** ก็ได้ ทุกไฟล์ในโฟลเดอร์นั้นจะนับรวม รวมถึงไฟล์ที่เพิ่มทีหลังด้วย

ทั้งสองอย่างแสดงใน Mod Menu และรายการม็อด (`fabric.mod.json`, `quilt.mod.json`, `mods.toml`) แยกเป็นหัวข้อ: **License** แล้วตามด้วย **Credits** ที่มีผู้สร้าง และผู้ร่วมทำทีละบรรทัด เช่น "Reff Pixels - app icons (reffpixels.itch.io)" และเครดิตยังถูกบันทึกเป็น `CREDITS.txt` ใน .jar ด้วย

ใส่ **ลิงก์เว็บไซต์** และ **ลิงก์แจ้งปัญหา (Issues)** ได้ด้วย จะกลายเป็นปุ่ม Website / Issues ใน Mod Menu และรายการม็อด

## 3. หน้าจอ Workspace

```
┌──────── แถบบน: หน้าแรก · เลิกทำ/ทำซ้ำ · เป้าหมาย · ▶ ทดสอบ · ⬇ ส่งออก · โฟลเดอร์ · ตั้งค่า ────────┐
│ แผงซ้าย        │                                                  │ แผงขวา               │
│  โหนด          │              ผืนงาน (กราฟโหนด)                   │  คุณสมบัติ           │
│  ไฟล์          │                                                  │  ของโหนดที่เลือก     │
│  ไอเทมเกม      │                                                  │                      │
├────────────────┴──────────────────────────────────────────────────┴──────────────────────┤
│ แผงล่าง: ปัญหา · คอนโซล                                                                   │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

- **แถบบน**
  - **เป้าหมาย** เลือก loader + เวอร์ชันที่ใช้ตรวจ ทดสอบ และส่งออก
  - ปุ่ม **▶ ทดสอบในเกม** (Ctrl+Enter) และ **⬇ ส่งออก .jar**
  - ปุ่มโฟลเดอร์เปิดโฟลเดอร์ build
  - ปุ่มฟันเฟืองเปิดตั้งค่า
- **แผงซ้าย**
  - **โหนด**: คลังโหนด ค้นหาได้ ลากไปวางบนผืนงาน
  - **ไฟล์**: ไฟล์ในโปรเจกต์
  - **ไอเทมเกม**: ไอเทมทุกชิ้นของเกมและ Farmer's Delight
- **แผงขวา (คุณสมบัติ)**
  - แสดงค่าของโหนดที่เลือก
  - ถ้าไม่ได้เลือกอะไร จะแสดง **ตั้งค่าโปรเจกต์**: ชื่อ, Mod ID, ผู้สร้าง, เวอร์ชัน, คำอธิบาย, **โลโก้ม็อด**, ไอเทมที่ไม่อยู่ในแท็บครีเอทีฟจะให้ทำอย่างไร และ loader/เวอร์ชัน
- **ปัญหา**
  - ตรวจกราฟให้ตลอด ข้อผิดพลาด (แดง) ต้องแก้ก่อนทดสอบ ส่วนคำเตือน (เหลือง) เป็นแค่คำแนะนำ
  - คลิกที่รายการเพื่อกระโดดไปที่โหนดนั้น
  - ถ้าขึ้น "ไม่มีปัญหา — พร้อมทดสอบ!" ก็พร้อมแล้ว
- **คอนโซล**
  - แสดง log ของ Gradle และ Minecraft ตอนสร้างหรือทดสอบ
  - **🧹 ล้าง build** ลบโฟลเดอร์ build ของเป้าหมายที่เลือก ใช้ตอน build ค้างหรือเสีย

ปรับขนาดแผงล่างและแผงข้างได้ด้วยการลากขอบ

### หน้าจอแบบ IDE (แบบ VS Code)

ปุ่มเลย์เอาต์ที่แถบบน (หรือที่แถบสถานะ) ใช้สลับระหว่าง **หน้าจอแบบ IDE** กับหน้าจอแบบเดิม

- **แถบไอคอน** ซ้ายสุด: โหนด, ไอเทมเกม, ไฟล์ และ **โค้ด** กดไอคอนเพื่อแสดงในแถบข้าง กดซ้ำเพื่อซ่อน
- **แท็บ**: กราฟโหนดเป็นแท็บแรกเสมอ ไฟล์โค้ดและโมเดล 3D เปิดเป็นแท็บแยก กดปุ่มกลางเมาส์หรือ × เพื่อปิด ถ้ามี ● แปลว่ายังไม่ได้บันทึก
- **โค้ด**: โปรเจกต์ Gradle ที่ "ทดสอบในเกม" ใช้ build ของเป้าหมายที่เลือก (Java, JSON, ไฟล์ภาษา ฯลฯ) สร้างจากโหนดของคุณ และอัปเดตเองตอนแก้กราฟ
  - **แก้ไขไฟล์เหล่านี้ได้** ไฟล์ที่แก้จะมีเครื่องหมาย ✎ ถูกเก็บในโปรเจกต์ (แยกตาม loader และเวอร์ชัน) และถูกใช้แทนไฟล์ที่แอปสร้างตอนทดสอบหรือส่งออก แก้โหนดแล้วไฟล์นั้นจะไม่อัปเดตตาม กด **คืนค่าเป็นของที่แอปสร้าง** เพื่อยกเลิกที่แก้ ถ้าจะเขียนคลาสใหม่ของตัวเองให้ใช้โหนดคลาส Java
- **แถบสถานะ** ด้านล่าง: จำนวนปัญหา (กดเพื่อดู), เป้าหมาย, ความคืบหน้าการ build, ตำแหน่งเคอร์เซอร์ในไฟล์โค้ด, สถานะการบันทึก
- **Command palette**: Ctrl+Shift+P สั่งได้ทุกอย่าง (ทดสอบ, ส่งออก, สร้างโมเดล 3D, เปลี่ยนเป้าหมาย, แสดง/ซ่อนแผง …) Ctrl+P เปิดไฟล์โค้ดด้วยชื่อ

## 4. การใช้โหนดและสาย

ม็อดหนึ่งตัวประกอบด้วย **โหนด** ที่ต่อกันด้วย **สาย** โหนดหนึ่งตัวคือของหนึ่งอย่าง (เท็กซ์เจอร์ ไอเทม สูตรคราฟ ฯลฯ) สายส่งของจาก **ขาออก** (ด้านขวา) ไปยัง **ขาเข้า** (ด้านซ้าย)

### เพิ่มโหนด

- ลากจากคลัง **โหนด** มาวางบนผืนงาน
- **คลิกขวา** หรือกด **Space** บนผืนงานเพื่อเปิดเมนูเพิ่มโหนด พิมพ์ค้นหาได้ แล้วใช้ลูกศรกับ Enter
- **ลากสายจากขาไปปล่อยที่ว่าง** เพื่อเพิ่มโหนดที่ต่อสายไว้แล้ว
- **ลากไฟล์** (PNG, OGG, โมเดล ฯลฯ) มาวางบนผืนงาน แอปจะนำเข้าไฟล์และสร้างโหนดให้

### ต่อสาย

- ลากจากขาหนึ่งไปอีกขาหนึ่ง **สีของขาบอกชนิด** และต่อได้เฉพาะชนิดที่เข้ากัน เช่น ขาเท็กซ์เจอร์ (ส้ม) รับได้แต่เท็กซ์เจอร์ ส่วนไอเทม (น้ำเงิน) ต่อเข้าขาวัตถุดิบ (ฟ้า) ได้ด้วย

  | สี | ชนิด |
  |---|---|
  | 🔵 น้ำเงิน | ไอเทม |
  | 🩵 ฟ้า | วัตถุดิบ (ไอเทมหรือแท็ก) |
  | 🟠 ส้ม | เท็กซ์เจอร์ |
  | 🟣 ม่วง | โมเดล 3D / บล็อก |
  | 🌸 ม่วงชมพู | โมเดลเกราะ 3D |
  | 🟢 เขียว | ไฟล์เสียง / เสียงในเกม |
  | 🔴 แดง | วัสดุเครื่องมือ |
  | 🟧 ส้มเข้ม | วัสดุเกราะ |
  | 🩷 ชมพู | เอฟเฟกต์ |
  | 💜 ม่วงอ่อน | อนิเมชัน |
  | ⚪ เทา | อะไรก็ได้ (จุดพักสาย) |

- บางโหนดมีขาที่ **เพิ่มเองได้**: ต่อช่องว่างช่องสุดท้ายเมื่อไหร่ ช่องใหม่จะโผล่ขึ้นมา เช่น วัตถุดิบในสูตรคราฟ และไอเทมในแท็บครีเอทีฟ

### ถอดสาย

- คลิกที่สาย แล้วกดปุ่ม **×** บนสาย
- **คลิกขวาที่สาย → ถอดสายเส้นนี้**
- **Alt+คลิกที่ขา** เพื่อถอดสายของขานั้น
- **คลิกขวาที่โหนด** จะเห็นสายทั้งหมดที่ต่ออยู่ (คลิกเส้นที่ต้องการถอด) หรือเลือก **ถอดสายทั้งหมด**

### เลือกและเลื่อน

- ลากเมาส์ซ้ายบนที่ว่างเพื่อตีกรอบเลือก กด Ctrl+A เพื่อเลือกทั้งหมด
- ลากด้วยคลิกขวา, ปุ่มกลาง หรือ **กด Space ค้างแล้วลาก** เพื่อเลื่อนผืนงาน ใช้ล้อเมาส์ซูม
- **F** ปรับมุมมองให้เห็นทุกโหนด หรือเฉพาะโหนดที่เลือก
- **Delete** / Backspace ลบ, **Ctrl+C / Ctrl+V** คัดลอกและวาง (วางตรงตำแหน่งเมาส์), **Ctrl+D** ทำสำเนา
- **Ctrl+Z / Ctrl+Y** เลิกทำและทำซ้ำ

### ปิดโหนดชั่วคราว

กด **Ctrl+E**, ใช้เมนูคลิกขวาของโหนด หรือสวิตช์บนสุดในแผงคุณสมบัติ เพื่อ **ปิด** โหนด โหนดยังอยู่บนผืนงานพร้อมป้าย **ปิด** แต่จะไม่ถูกใส่ในม็อด เหมาะกับการลองของโดยไม่ต้องลบ

### จัดระเบียบ

- **จุดพักสาย** เป็นจุดเล็ก ๆ ไว้หักมุมสาย
- **คอมเมนต์** เป็นโน้ตสีบนผืนงาน

## 5. ไฟล์ (Assets)

แท็บ **ไฟล์** เป็นต้นไม้ไฟล์แบบ VS Code:

- กด **นำเข้า…** หรือลากไฟล์มาวางที่หน้าต่าง รูป โมเดล เสียง และอนิเมชันจะเข้าโฟลเดอร์ที่ตรงชนิด
- ลากแถวไปวางบนโฟลเดอร์เพื่อย้าย ใช้ **โฟลเดอร์ใหม่** เพื่อจัดกลุ่ม
- **F2** เปลี่ยนชื่อ, **Del** ลบ ไฟล์ที่ลบจะไปอยู่ในถังขยะ กู้คืนได้
- ลากไฟล์ไปวางบนผืนงาน หรือกด **เพิ่มลงผืนงาน** เพื่อสร้างโหนด

ไฟล์ที่รองรับ:

| ชนิด | ไฟล์ | หมายเหตุ |
|---|---|---|
| เท็กซ์เจอร์ | `.png` | ปกติใช้ 16×16 ภาพเคลื่อนไหวให้เรียงเฟรมแนวตั้ง (16×64 = 4 เฟรม) |
| โมเดล 3D | `.json` (โมเดลบล็อก/ไอเทมแบบ Java), `.bbmodel` (Blockbench) |  |
| โมเดลเกราะ 3D | `.bbmodel`, `.geo.json` (GeckoLib) | ใช้โมเดล `.json` ผ่านโหนดโมเดล 3D ก็ได้ |
| อนิเมชัน | `.animation.json` (Blockbench / GeckoLib) |  |
| เสียง | `.ogg` | ไฟล์ชนิดอื่นแปลงได้ (ดูด้านล่าง) |

### โปรแกรมทำโมเดล 3D

Blockbench แบบง่ายในตัวแอป สร้างโมเดลด้วยปุ่ม **🧊 โมเดล** ในแท็บไฟล์ (หรือ "สร้างโมเดล 3D ใหม่" ใน command palette) หรือเปิดโมเดลเดิม: คลิกขวาที่ไฟล์ `models/….json` → **แก้ไขในโปรแกรมทำโมเดล** หรือกดปุ่ม **แก้ไขในโปรแกรมทำโมเดล** ที่โหนดโมเดล 3D (จะใช้เท็กซ์เจอร์ที่ต่อสายไว้)

- **กล่อง** (ซ้าย): เพิ่ม คัดลอก ลบ และตั้งชื่อกล่อง คลิกกล่องในมุมมอง 3D เพื่อเลือก
- **เครื่องมือ**: เลือก, ย้าย, ย่อ/ขยาย, หมุน และวาด ลากลูกศร / จุดจับ / วงแหวน ตั้ง **จับระยะ** ได้ (ปกติ 1 พิกเซล) หรือพิมพ์ตัวเลขทางขวา: **จาก** / **ถึง** เป็นพิกเซล (16 = 1 บล็อก กรอบสีม่วงคือ 1 บล็อก)
- **หมุน**: แกนเดียว −45° ถึง 45° ทีละ 22.5° (ตามที่ Minecraft รองรับ) ใช้เครื่องมือหมุนหรือเลือกทางขวา
- **การควบคุม**: เมาส์และปุ่มเป็นไปตามรูปแบบที่เลือกใน **ตั้งค่า → โปรแกรมทำโมเดล** (ปุ่ม 🎮 บนแถบของโปรแกรมทำโมเดลเปิดหน้านี้) ค่าพื้นฐาน:

  |  | Blockbench (ค่าเริ่มต้น) | Maya | Blender |
  |---|---|---|---|
  | หมุนมุมมอง | ลากซ้าย (โหมดวาด: ลากขวา) | Alt + ลากซ้าย | ลากปุ่มกลาง |
  | เลื่อนมุมมอง | ลากขวา | Alt + ลากปุ่มกลาง | Shift + ลากปุ่มกลาง |
  | ซูม | ล้อเมาส์ | ล้อเมาส์ หรือ Alt + ลากขวา | ล้อเมาส์ หรือ Ctrl + ลากปุ่มกลาง |
  | เลือก / ย้าย / ย่อขยาย / หมุน / วาด | V / G / S / R / B | Q / W / R / E / B | W / G / S / R / B |
  | ซูมไปที่ที่เลือก / ดูทั้งหมด | F / A | F / A | . / Home |

  เลือกค่าพื้นฐานแล้วปรับต่อได้ทุกอย่าง (จะกลายเป็น **กำหนดเอง**): ปุ่มเมาส์และปุ่มกดค้างสำหรับหมุน เลื่อน ซูม, กลับทิศหมุน (ซ้าย/ขวา, ขึ้น/ลง) และกลับทิศซูม, ความเร็ว และปุ่มลัดของทุกเครื่องมือ (คลิกช่องปุ่มแล้วกดปุ่มใหม่) ช่อง **แบบโค้ด** แสดงค่าเดียวกันเป็น JSON และปุ่ม `{ }` เปิดเป็นไฟล์ `model-controls.json` ในแท็บ IDE แก้ได้แบบเขียนโค้ด (แก้ถูกต้องแล้วใช้ได้ทันที)

- **หน้า**: เลือกหน้า เปิด/ปิดหน้า เลือกช่องเท็กซ์เจอร์ หมุนลาย และใช้ UV อัตโนมัติ (ตามขนาดกล่อง) หรือพิมพ์ UV เอง
- **เท็กซ์เจอร์**: ช่อง #0–#3 ชี้ไปที่รูปในโปรเจกต์ กด **เท็กซ์เจอร์ใหม่** เพื่อสร้าง PNG เปล่าขนาด 16×16, 32×32 หรือ 64×64
- **วาด**: ดินสอ ยางลบ เทสี ดูดสี และสีที่ใช้ล่าสุด วาดบนโมเดลได้เลย หรือวาดบนภาพเท็กซ์เจอร์
- **มุมมอง UV** (สลับ **3D / UV / 3D + UV**): ภาพเท็กซ์เจอร์ของช่องที่เลือก พร้อมกรอบของทุกหน้าที่ใช้ภาพนี้ (N S E W U D หน้าที่เลือกเป็นสีส้ม) คลิกหน้าเพื่อเลือก ลากเพื่อย้าย UV ลากมุมเพื่อย่อขยาย (จับตามพิกเซลของภาพ) กด **กาง UV กล่องนี้** / **กาง UV ทั้งหมด** เพื่อจัดหน้าเป็นรูปกล่องกางออก (บน/ล่างอยู่เหนือด้านทั้งสี่) ไว้วาดได้ง่าย กด **UV อัตโนมัติ** เพื่อกลับไปใช้ UV อัตโนมัติของ Minecraft
- **บันทึก** (Ctrl+S) จะบันทึกไฟล์โมเดล `.json` และรูป PNG ที่วาด Ctrl+Z / Ctrl+Y เลิกทำ/ทำซ้ำ จะใช้โมเดลในม็อด ให้เพิ่มโหนดโมเดล 3D ที่ใช้ไฟล์นี้ แล้วต่อเท็กซ์เจอร์ตามลำดับช่อง (#0, #1 …)

### แปลงเสียงเป็น OGG

Minecraft เล่นได้แค่ `.ogg` กด **แปลงเสียง** ในแท็บไฟล์ แล้วเลือกไฟล์ MP3/WAV/MP4/M4A/FLAC/AAC/WEBM/MOV… แอปจะแปลงเป็น `.ogg` เก็บไว้ในโปรเจกต์

- แนะนำให้เปิด **โมโน** เพราะเฉพาะเสียงโมโนที่จะเบาลงตามระยะในเกม
- **ความดัง** ใช้ปรับความดังของเสียง

## 6. ไอเทมเกม (vanilla และ Farmer's Delight)

แท็บ **ไอเทมเกม** แสดงไอเทมทุกชิ้นของเวอร์ชัน Minecraft ที่เลือก พร้อมไอคอนและชื่อไทย/อังกฤษ

- ครั้งแรกให้กด **โหลดไอเทมของ Minecraft** (ดาวน์โหลดจาก Mojang ครั้งเดียว ประมาณ 25 MB) ไอเทมของ Farmer's Delight ก็โหลดได้แบบเดียวกัน
- ค้นหาได้ทั้งชื่อไทย ชื่ออังกฤษ หรือ ID กรองตามหมวด หรือสลับไปดู **แท็ก** (เช่น `minecraft:planks` คือไม้กระดานชนิดไหนก็ได้)
- **ลาก** ไอเทมมาวางบนผืนงาน หรือ **ดับเบิลคลิก** เพื่อสร้างโหนด **ไอเทมที่มีอยู่แล้ว** หรือ **แท็กไอเทม** แล้วต่อเข้าสูตรคราฟได้

เพิ่มโหนดเหล่านี้เองจากหมวด **เครื่องมือ** ก็ได้: **ไอเทมที่มีอยู่แล้ว** (`minecraft:diamond` หรือไอเทมจากม็อดอื่น) และ **แท็กไอเทม** (`minecraft:planks`) โหนดแท็กไอเทมจะแสดงไอเทมในแท็กเป็นรูป (เป็นตารางในแผงด้านขวา และบนโหนดอีกเล็กน้อย) ชี้เมาส์ที่รูปเพื่อดูชื่อไอเทม

### ไอเทมของม็อดอื่น (Modrinth หรือไฟล์ .jar)

กด **+ ม็อด** ในแท็บไอเทมเกม จะเปิดหน้าแกลเลอรีม็อดจาก Modrinth ของเวอร์ชัน Minecraft ที่เลือก มีภาพ คำอธิบาย ยอดดาวน์โหลด loader และหมวดของแต่ละม็อด ค้นหา เรียงลำดับ (ตรงที่สุด ดาวน์โหลดมากสุด ใหม่ล่าสุด …) กด **ดูเพิ่ม** หรือ **↗** เพื่อเปิดหน้าม็อด ส่วน **เลือกไฟล์ .jar…** / **เลือกโฟลเดอร์ mods…** ใช้อ่านม็อดที่มีในเครื่อง

ม็อดที่เพิ่มแต่ละตัวเลือกได้ว่าใช้ทำอะไร (ในแกลเลอรี หรือข้างรายการในแท็บไอเทมเกม):

- **ดูรายการไอเทมอย่างเดียว**: ไอเทม บล็อก (ชื่ออังกฤษ ไอคอน) แท็ก และ **พืช** ใช้ได้ในรายการไอเทม ตัวเลือกบล็อก ตัวอย่างแท็กไอเทม และรายการพืชของโหนด **เก็บเกี่ยวพืชในเกม**
- **ใส่ตอนทดสอบ**: ใส่ม็อดนี้ตอนกด **ทดสอบในเกม** ด้วย (เวอร์ชันของ loader ที่โปรเจกต์ใช้ พร้อมม็อดที่มันต้องใช้) ม็อดของเราไม่ต้องพึ่งม็อดนี้
- **ตัวเลือก (optional)**: ใส่ตอนทดสอบ และเขียนเป็น dependency แบบไม่บังคับในไฟล์ข้อมูลม็อด (fabric.mod.json `suggests`, mods.toml `mandatory=false` / `type="optional"`)
- **ต้องมี (required)**: ใส่ตอนทดสอบ และผู้เล่นต้องลงม็อดนี้ด้วย (ถ้าไม่มี เกมจะไม่ยอมเปิด)

หมายเหตุ: ม็อดที่ไม่มีเวอร์ชันของ loader ที่โปรเจกต์ใช้ จะไม่ถูกใส่ตอนทดสอบ (มีแจ้งใน log) ไฟล์ .jar ใช้ได้กับ Minecraft เวอร์ชันเดียวและ loader เดียว ถ้าใช้กับเป้าหมายอื่นให้เลือกไฟล์ที่ตรงอีกครั้ง dependency ใช้ ID ม็อดในเกม ซึ่งอ่านได้ตอนโหลดไอเทมของม็อด ให้โหลดก่อนหนึ่งครั้งก่อน build ไฟล์ที่เลือกจะใส่ตอนทดสอบ ส่วนโฟลเดอร์ mods ทั้งโฟลเดอร์จะเป็นแบบดูรายการไอเทม (เปลี่ยนทีละม็อดได้) ปุ่ม **✕** ใช้เอาม็อดออกจากโปรเจกต์

> สกิน Steve/Alex ที่ใช้ดูตัวอย่างเกราะก็มาจากไฟล์เกมที่ดาวน์โหลดตรงนี้เช่นกัน แอปไม่ได้แนบไฟล์ของ Mojang มาด้วย

## 7. ไอเทม

โหนดไอเทมทุกตัวมี:

- **ชื่อที่แสดง (EN)** และ **ชื่อที่แสดง (ไทย)**
- **ID ในเกม**: ตัวพิมพ์เล็ก ตัวเลข และ `_` กด **สร้างจากชื่อ** เพื่อเติมให้อัตโนมัติ

แผงคุณสมบัติจะแสดงคำสั่ง `/give` ของไอเทมนั้นด้วย

### ไอเทม

ไอเทมทั่วไป

- **ขาเข้า**
  - **ไอคอน / เท็กซ์เจอร์**
  - **โมเดล 3D** (ไม่บังคับ): ถือในมือแล้วเห็นเป็น 3D ถ้าต่อไอคอนไว้ด้วย ไอคอนนั้นจะใช้ในช่องเก็บของ
  - **วางเป็นบล็อก** (ไม่บังคับ): ใช้ไอเทมแล้ววางบล็อก เช่น เมล็ดที่วางเป็นพืช
- **คุณสมบัติ**
  - จำนวนซ้อนสูงสุด (1–64)
  - ความหายาก (สีของชื่อ)
  - ทนไฟ
  - ประกายเอนชานต์
  - ถือแบบเครื่องมือ
  - **ใส่บนหัวได้** (ดูด้านล่าง)

### อาหาร

เหมือนไอเทม แต่เพิ่ม:

- ฟื้นฟูความหิว, ความอิ่ม, กินได้แม้อิ่ม, กินเร็ว
- **เสียงตอนกิน**:
  - _กิน_: เสียงเคี้ยว
  - _ดื่ม_: เสียงกลืน และยกขึ้นดื่มแบบขวดยา
- ขา **เอฟเฟกต์ตอนกิน** ได้สูงสุด 3 ขา
- ขา **ความสามารถตอนกิน** ได้สูงสุด 3 ขา: แช่แข็งแบบหิมะผง, ติดไฟ, ฟ้าผ่า, วาร์ปสุ่ม, ล้างเอฟเฟกต์ทั้งหมด (ดูหัวข้อ 11)
- ขา **ค่าน้ำ (ส่วนเสริม)** (ดูด้านล่าง)

### ค่าน้ำ (ส่วนเสริม)

อยู่ในหมวด **ส่วนเสริม (ม็อดอื่น)** ของคลังโหนด ต่อเข้าโหนดอาหาร เพื่อให้อาหารหรือเครื่องดื่มนั้นมีค่าน้ำในม็อดความกระหายน้ำ:

| ค่า | ความหมาย |
|---|---|
| **ฟื้นค่าน้ำ** | 1–20 แต้มในหลอดน้ำ เหมือนค่าความหิว (ขวดน้ำประมาณ 6) |
| **ความชุ่มชื้น** | 0–20 คล้ายความอิ่มของอาหาร เป็นค่าน้ำสำรองที่ถูกใช้ก่อนหลอดลด (ใน Thirst Was Taken เรียกว่า quenched) |

ม็อดของเรา **ไม่ต้องพึ่ง** ม็อดพวกนี้ ถ้าผู้เล่นลงม็อดใดม็อดหนึ่งไว้ กินหรือดื่มอาหารนี้แล้วจะได้ค่าน้ำด้วย:

| ม็อด | เวอร์ชัน | ทำงานอย่างไร |
|---|---|---|
| Tough As Nails | 1.18.2 ขึ้นไป | แท็กไอเทม (ความชุ่มชื้นปัดเป็นขั้นละ 10 %) |
| Thirst Was Taken | Forge 1.18.2–1.20.1, NeoForge 1.21.1 | event ลงทะเบียนของม็อด (อาหาร/เครื่องดื่มตาม "เสียงตอนกิน") |
| Thirst Was Taken 2 | 1.20.1 และ 1.21.1 | ไฟล์ข้อมูล |
| Legendary Survival Overhaul | Forge 1.20.1, NeoForge 1.21.1 | ไฟล์ข้อมูล |
| Thirsty – Thirst System | Fabric/Quilt 1.20.1 | เพิ่มเข้ารายการไอเทมของม็อดตอนเริ่มเวิลด์ |

### เครื่องมือ / อาวุธ

ดาบ อีเต้อ ขวาน พลั่ว หรือจอบ

- **ขาเข้า**
  - เท็กซ์เจอร์
  - **วัสดุ** (ไม่บังคับ ไม่ใส่ = เหล็ก)
  - โมเดล 3D
  - ขา **เอฟเฟกต์ใส่ศัตรูที่ตี** ได้สูงสุด 3 ขา
  - ขา **ความสามารถตอนตี** ได้สูงสุด 3 ขา (ติดไฟ, สายฟ้า, แช่แข็ง ดูหัวข้อ 11)
  - ขา **โบนัสค่าสถานะ** (ดูหัวข้อ 11)
- **คุณสมบัติ**: ประเภท, ดาเมจเพิ่มเติม, ค่าความเร็วโจมตี, ทนไฟ, ความหายาก, ใส่บนหัวได้
- **ความคงทน**: ใช้ได้กี่ครั้งก่อนพัง (0 = ตามวัสดุ) เปิด **ไม่มีวันพัง** แล้วจะไม่เสียความคงทนเลย (คำอธิบายไอเทมขึ้นว่า "Unbreakable")

### วัสดุเครื่องมือ

ค่าสถานะที่เครื่องมือทั้งชุดใช้ร่วมกัน: ความทนทาน, ความเร็วขุด, ดาเมจเพิ่ม, ระดับการขุด (ไม้ → เนเธอไรต์), ค่าเอนชานต์ มีขา **ซ่อมด้วย** (ใช้ตอนซ่อมที่ทั่ง) ต่อขาออกของโหนดนี้เข้าขา **วัสดุ** ของเครื่องมือแต่ละชิ้น

### ไอเทมที่สวมบนหัว

เปิด **ใส่บนหัวได้** ที่ไอเทม อาหาร หรือเครื่องมือ แล้วผู้เล่นจะ:

- คลิกขวาเพื่อสวมได้ (ปิด **คลิกขวาเพื่อสวมได้** ถ้าอยากให้ใส่ได้แค่วิธีถัดไป) หรือ
- ลากหรือ Shift+คลิกใส่ช่องหมวก

คำอธิบายไอเทมจะมีบรรทัดสีชมพูบอกว่าสวมได้ ถ้าไอเทมมีโมเดล 3D จะแสดงตามค่า **Head** ใน Blockbench (Display → Head)

## 8. บล็อก

โหนดบล็อกทั้งสองแบบมีขาออก 2 ขา:

- **ไอเทมบล็อก**: ของที่ถือในมือ (ใช้ในสูตรคราฟและแท็บ)
- **บล็อก (สำหรับวาง)**: ต่อเข้าขา **วางเป็นบล็อก** ของไอเทม

### บล็อก

บล็อกลูกบาศก์ปกติ

- **รูปแบบเท็กซ์เจอร์**:
  - _เหมือนกันทุกด้าน_
  - _บน / ข้าง / ล่าง_: ต่อเท็กซ์เจอร์ **ด้านบน** และ **ด้านล่าง** เพิ่ม
  - _เสา_: แบบท่อนไม้ หมุนได้
- ขา **ของที่ดรอป**: ไม่ต่อ = ดรอปตัวเอง

### บล็อก 3D

บล็อกที่ใช้โมเดล Blockbench (ต่อโหนด **โมเดล 3D** เข้าขา **โมเดล**)

- hitbox คำนวณจากโมเดลอัตโนมัติ
- **หันหน้าเข้าหาผู้เล่นตอนวาง**
- **มีการชน**

### พืช (ปลูกได้)

หมวด **การเกษตร** พืชที่โตได้สูงสุด 8 ระยะ

- ขา **ระยะการโต 1–8**: เท็กซ์เจอร์ของแต่ละระยะ (ขาสุดท้ายที่ต่อคือโตเต็มที่) ขา **ผลผลิต**: ไอเทมที่ได้
- ต่อขา **บล็อก (ต่อเข้าเมล็ด)** เข้าขา **วางเป็นบล็อก** ของไอเทมเมล็ด แล้วเมล็ดจะปลูกพืชนี้
- **รูปทรง**: `#` แบบข้าวสาลี หรือ `X` แบบดอกไม้ / พุ่มเบอร์รี **ปลูกบน**: ดินไถ หรือ ดินไถ ดิน และหญ้า
- **เวลาโตเต็มที่**: วินาทีจนโตเต็มที่ (0 = สุ่มแบบข้าวสาลี)
- **หลังเก็บเกี่ยว**:
  - _หายไป ต้องปลูกเมล็ดใหม่_ (แบบข้าวสาลี) ทุบแล้วได้ผลผลิตและเมล็ดคืน (**ได้เมล็ดคืนต่ำสุด / สูงสุด**)
  - _ปลูกใหม่เอง_ (แบบโหนด **เก็บเกี่ยวพืชในเกม**): เก็บแล้วได้ผลผลิตและเมล็ดคืน หักเมล็ด 1 เมล็ดที่ปลูกกลับลงดิน แล้วพืชโตใหม่ตั้งแต่ต้น ต้องเก็บแบบคลิกขวา
  - _ต้นยังอยู่ โตใหม่ตามเวลาคูลดาวน์_: เก็บแล้วได้ผลผลิต ต้นย้อนกลับไประยะที่เลือก แล้วโตใหม่ตาม **คูลดาวน์**
- **วิธีเก็บเกี่ยว**: ทุบ, คลิกขวา, **กดคลิกขวาค้าง** ตามเวลาเก็บ หรือ **คลิกขวาครั้งเดียวแล้วยืนนิ่ง** ตามเวลาเก็บ (ขยับแล้วต้องคลิกใหม่) ระหว่างเก็บจะมีเวลาแสดงบนจอ ต่อโหนด **หน้าต่างเวลา** เข้าขา **หน้าต่างเวลา** เพื่อเลือกหน้าตา (ถ้าไม่ต่อ: เป็นข้อความเหนือแถบไอเทม)
- **ต้องย่อตัว (Shift) ถึงจะเก็บได้**: ต้องย่อตัวแล้วคลิกขวาถึงจะเก็บด้วยมือได้ (ลุกขึ้นระหว่างเก็บจะหยุด) คลิกขวาปกติจะทำงานแบบเดิมของเกม
- **จำนวนผลผลิตต่ำสุด / สูงสุด**
- **เมื่อผู้เล่นทุบพืช**: _ได้ของตามปกติ_, _ได้ของเฉพาะตอนโตเต็มที่_ (ทุบต้นอ่อนแล้วไม่ได้อะไรเลย แม้แต่เมล็ด) หรือ _ไม่ได้อะไรเลย_ (ต้องเก็บด้วยมือเท่านั้นถึงจะได้ผลผลิต — ใช้คู่กับการเก็บแบบคลิกขวา) การเก็บด้วยมือและโหมดสร้างสรรค์ไม่มีผล
- **เก็บได้ในโหมดผจญภัย (Adventure)** (แสดงเมื่อเก็บแบบคลิกขวา): ปิด = ผู้เล่นโหมดผจญภัยเก็บด้วยมือไม่ได้

### เก็บเกี่ยวพืชในเกม

ให้พืชของ Minecraft, Farmer's Delight หรือม็อดอื่นใช้ระบบเก็บเกี่ยวด้วยมือแบบเดียวกัน พืชยังโตตามปกติของเกม และทุบได้ตามปกติ

- **พืช**: ข้าวสาลี, แครอท, มันฝรั่ง, บีทรูท, หูดเนเธอร์, พุ่มสวีทเบอร์รี, โกโก้ หรือกะหล่ำปลี หัวหอม มะเขือเทศ และข้าวของ Farmer's Delight เลือก **บล็อกอื่น** แล้วพิมพ์ ID บล็อกที่มีค่า `age` ได้ (พืชของม็อดอื่น)
- **วิธีเก็บเกี่ยว**: คลิกขวา, กดคลิกขวาค้าง หรือคลิกขวาครั้งเดียวแล้วยืนนิ่ง พร้อม **เวลาเก็บ**
- **ต้องย่อตัว (Shift) ถึงจะเก็บได้**: เหมือนโหนดพืช
- **หลังเก็บเกี่ยว**:
  - _แบบปกติของเกม / ม็อด_: เบอร์รีและมะเขือเทศเด็ดผลแล้วต้นยังอยู่ อย่างอื่นแตกเหมือนตอนทุบ (ได้ของตามปกติ)
  - _ปลูกใหม่เอง_: ได้ของตามปกติหักเมล็ดออก 1 เมล็ด แล้วพืชเริ่มโตใหม่ตั้งแต่ต้น
  - _ต้นยังอยู่ ย้อนกลับไประยะที่เลือก_: ได้ของตามปกติ แล้วย้อนกลับไประยะที่เลือกและโตใหม่ตามปกติของเกม
- **ผลผลิตเข้าตัวทันที**: ปิด = ดรอปบนพื้นแบบปกติ · เปิด = เข้าช่องเก็บของเลย (ถ้าเต็มจะดรอปที่เท้า) โหนดพืชก็มีตัวเลือกนี้สำหรับการเก็บด้วยมือ
- **เมื่อผู้เล่นทุบพืช**: เลือกได้ 3 แบบเหมือนโหนดพืช เช่น _ไม่ได้อะไรเลย_ เพื่อบังคับให้ผู้เล่นเก็บด้วยมือ
- **เก็บได้ในโหมดผจญภัย (Adventure)**: ปิด = ผู้เล่นโหมดผจญภัยเก็บพืชเหล่านี้ด้วยมือไม่ได้
- พืชละหนึ่งโหนด พืชของ Farmer's Delight มีเฉพาะเป้าหมายที่มี Farmer's Delight (แผง Problems จะแจ้ง) และตอน "ทดสอบในเกม" จะใส่ Farmer's Delight ให้อัตโนมัติ

### หน้าต่างเวลา

หมวด **เครื่องมือ** หน้าต่างเวลาบนจอ ทั้งตอนเก็บพืชด้วยมือและตอนทุบบล็อก ต่อขาออกเข้าขา **หน้าต่างเวลา** ของโหนดพืช เก็บเกี่ยวพืชในเกม บล็อกเกิดใหม่ หรือกฎการทุบบล็อก (หน้าต่างเดียวใช้กับหลายโหนดได้) แผงด้านขวามีตัวอย่างบนจอเกมจำลองให้ดูทันที

- **แบบ**:
  - _ข้อความ_: `กำลังเก็บ ■■■□□□□□□□ 1.2 วิ` (แบบเดิม)
  - _หลอดที่เพิ่มขึ้น_
  - _วงกลมที่เต็มขึ้นรอบเป้ากลางจอ_ (ตามเข็มนาฬิกาจากด้านบน)
- **สี** และสำหรับหลอดกับวงกลมมี **สีพื้นหลัง** และ **ความทึบพื้นหลัง**
- ข้อความและหลอด: **ตำแหน่ง** (ใต้เป้ากลางจอ, เหนือแถบไอเทม, ด้านบนของจอ) และ **เลื่อนลง** (ติดลบ = ขึ้น)
- หลอด: **ความยาว** และ **ความสูง** วงกลม: **ขนาด** (รัศมี) และ **ความหนาเส้น** ถ้าหนาเท่าขนาดจะเป็นวงกลมทึบ
- **แสดงวินาทีที่เหลือ**

### กฎการทุบบล็อก (อุปกรณ์และระดับแร่)

หมวด **บล็อก** กำหนดให้บล็อกต้องใช้อุปกรณ์และระดับการขุด (ระดับแร่) ที่กำหนด — ใช้ได้กับบล็อกของ Minecraft ของม็อดอื่น และของม็อดเราเอง

- **บล็อก (เลือกได้หลายอัน)**: ติ๊กบล็อกในรายการ (พิมพ์เพื่อค้นหา ปุ่ม **ติ๊กทั้งหมด … อันที่พบ** จะติ๊กทุกผลลัพธ์ เช่น ค้นหา `ore`) เพิ่ม ID ของม็อดอื่น เช่น `othermod:ruby_ore` (ใส่หลายอันพร้อมกันได้ คั่นด้วยช่องว่างหรือจุลภาค) เพิ่มแท็ก เช่น `#minecraft:logs` หรือลากบล็อกจากแท็บ **ไอเทมเกม** มาวาง · บล็อกของม็อดเรา: ติ๊กในรายการ หรือต่อขา **บล็อก** เข้าขา **บล็อกของม็อด**
- **อุปกรณ์ที่ต้องใช้**: อีเต้อ ขวาน พลั่ว จอบ ดาบ กรรไกร หรือ _เครื่องมืออะไรก็ได้_ (ดูแค่ระดับ)
- **ระดับขั้นต่ำ (ระดับแร่)**: ไม้/ทอง หิน เหล็ก เพชร หรือเนเธอไรต์ขึ้นไป เครื่องมือของม็อดเรานับตามระดับการขุดของวัสดุเครื่องมือ
- **ถ้าใช้อุปกรณ์ไม่ถูก**: _ทุบแตกแต่ไม่ได้ของ_ (แบบขุดหินด้วยมือ) หรือ _ทุบไม่ได้เลย_
- **แจ้งผู้เล่นว่าต้องใช้อุปกรณ์อะไร**: ข้อความสีแดงเหนือแถบไอเทม สร้างให้อัตโนมัติ (เช่น "ต้องใช้อีเต้อระดับเหล็กขึ้นไปถึงจะได้ของ") หรือเขียนเองทั้งภาษาอังกฤษและไทย
- **แสดงเวลาตอนทุบ**: แบบเดียวกับการเก็บพืชด้วยมือ ขณะทุบจะมีเวลาที่เหลือแสดงบนจอ ส่วนท่าทุบและรอยแตกยังมีตามปกติ ต่อโหนด **หน้าต่างเวลา** เข้าขา **หน้าต่างเวลา** เพื่อเลือกแบบข้อความ หลอด หรือวงกลม (ถ้าไม่ต่อ: เป็นข้อความเหนือแถบไอเทม) เวลาคิดตามความเร็วขุดจริงของอุปกรณ์ที่ถือ
- **ทุบได้ในโหมดผจญภัย (Adventure) ถ้าใช้อุปกรณ์ถูก**: ปกติโหมดผจญภัยทุบอะไรไม่ได้เลย · เปิด: ถ้าถืออุปกรณ์ที่ผ่านกฎจะทุบบล็อกเหล่านี้ได้ (อุปกรณ์จะได้รายการ "ทุบได้" ที่ซ่อนไว้ ถ้าผู้ทำแมพตั้งรายการไว้แล้วจะใช้ของเดิม) มือเปล่าทุบไม่ได้
- โหมดสร้างสรรค์ไม่โดนกฎ บล็อกที่อยู่ในสองกฎจะใช้กฎแรก แท็กบล็อกต้องใช้ Minecraft 1.18.2 ขึ้นไป และใน 1.21.2 ขึ้นไปดาบไม่มีระดับการขุด (ดาบอะไรก็ผ่าน)

### บล็อกเกิดใหม่ (ทรัพยากร)

หมวด **บล็อก** บล็อกของ Minecraft (หรือม็อดอื่น) ที่เก็บได้แบบพืชและเกิดใหม่ได้ — เหมาะกับจุดเก็บทรัพยากรในแมพผจญภัยหรือเซิร์ฟเวอร์

- **บล็อก (เลือกได้หลายอัน)**: เช่น แร่เหล็ก ท่อนไม้โอ๊ก `othermod:ruby_ore` หรือบล็อกของม็อดเราเอง (ติ๊กในรายการ หรือต่อขา **บล็อก** เข้าขา **บล็อกของม็อด**) แต่ละอันจะได้บล็อกของตัวเอง (`regen_iron_ore` ถ้า **คำนำหน้า ID** คือ `regen`) หน้าตาเหมือนต้นฉบับ (ใช้โมเดลของต้นฉบับ) และได้ของเหมือนต้นฉบับ บล็อกเต็มก้อน เช่น แร่ หิน ท่อนไม้ จะสวยที่สุด ใช้แท็กไม่ได้
- **วิธีเก็บเกี่ยว** แบบเดียวกับพืช: _ทุบ (ขุด)_ (ขุดเหมือนบล็อกทั่วไป ตั้ง **ความแข็ง** และ **ขุดเร็วด้วย** ได้ ต้องใช้อุปกรณ์ถูกแบบต้นฉบับถึงจะได้ของ ใช้ Fortune / Silk Touch ได้ และ **แสดงเวลาตอนทุบ** ได้) _กดคลิกซ้ายค้าง_ หรือ _คลิกซ้ายครั้งเดียวแล้วยืนนิ่ง_ ตาม **เวลาเก็บ** (มีเวลาแสดงบนจอ ต่อโหนด **หน้าต่างเวลา** เพื่อเลือกหน้าตา) _กดคลิกซ้ายค้าง_ ทำงานเหมือนการขุด: นับเฉพาะเวลาที่กดค้าง ปล่อยปุ่มแล้วหยุดทันที (เวลาบนจอหายไป) และหันไปบล็อกอื่นจะเริ่มนับใหม่ ถ้าเลือกแบบคลิกซ้ายจะทุบบล็อกไม่ได้ และเครื่องมือจะแกว่งตลอดตอนกดค้าง ในโหมดผจญภัยด้วย ทุกแบบต้องใช้อุปกรณ์ที่ขุดบล็อกต้นฉบับได้ เช่น อีเต้อไม้ขุดแร่เหล็กไม่ได้ (จะขึ้นข้อความ _ต้องใช้อุปกรณ์ที่ดีกว่านี้_)
- **ค่าคงทนเครื่องมือที่เสียต่อครั้ง** (แบบคลิกซ้าย): ไอเทมในมือหลักเสียค่าคงทนเท่านี้ทุกครั้งที่เก็บ (0 = ไม่เสีย) แบบ _ทุบ (ขุด)_ เสียค่าคงทนตามปกติของเกม โหมดสร้างสรรค์ไม่เสีย
- **ดรอปแทน (ไอเทม)**: ต่อไอเทมอะไรก็ได้ — ของเกม ของม็อดอื่น หรือของม็อดเรา — เพื่อให้ได้ไอเทมนั้น (**จำนวนต่ำสุด / สูงสุด**) แทนของที่บล็อกต้นฉบับดรอป
- เก็บแล้วจะกลายเป็น **บล็อกระหว่างรอเกิดใหม่** (ค่าเริ่มต้น `minecraft:bedrock` — ใส่ ID บล็อกอะไรก็ได้เพื่อใช้หน้าตานั้น) บล็อกนี้ทุบไม่ได้ ระเบิดไม่พัง ลูกสูบดันไม่ได้ และจะกลับมาเป็นบล็อกเดิมหลัง **เกิดใหม่หลังจาก** กี่วินาทีที่ตั้งไว้
- **ผลผลิตเข้าตัวทันที**, **เก็บได้ในโหมดผจญภัย** (แบบคลิกขวา)
- **วางได้เฉพาะ OP** คนอื่นวางแล้วจะมีข้อความแจ้ง บล็อกเหล่านี้อยู่ใน **แท็บครีเอทีฟของตัวเอง** (ตั้ง **ชื่อแท็บครีเอทีฟ** EN/ไทยได้) ต่อจากแท็บของเรา โหนดบล็อกเกิดใหม่ทุกอันที่ใช้ **คำนำหน้า ID** เดียวกันจะอยู่แท็บเดียวกัน (ถ้าอยากแยกแท็บให้ใช้คำนำหน้าอื่น) ในโหมดสร้างสรรค์ OP ทุบเพื่อเอาออกได้ตามปกติ

### ไฟล์ config (สำหรับเจ้าของเซิร์ฟเวอร์)

ม็อดที่มีพืชเก็บด้วยมือ บล็อกเกิดใหม่ หรือกฎการทุบบล็อก จะมีไฟล์ `config/<modid>-harvest.json` สร้างตอนเปิดเกมครั้งแรกด้วยค่าที่ตั้งในโหนด (ลบไฟล์เพื่อกลับไปค่าเริ่มต้น แก้แล้วต้องเปิดเกมใหม่) แก้ได้เฉพาะ **เวลา** และ **เพิ่มบล็อก** ค่าอื่นเป็นไปตามโหนด และจะมีหัวข้อเฉพาะสิ่งที่ม็อดมี (ไม่มีโหนดกฎการทุบ → ไม่มี `breakRules`)

- **crops**: พืชของเราที่เก็บแบบกดค้าง / ยืนนิ่ง → `harvestSeconds`
- **gameCrops**: หนึ่งชุดต่อโหนด **เก็บเกี่ยวพืชในเกม** (`"1"`, `"2"` … ตามลำดับโหนด `_crops` บอกว่ามีพืชอะไร) → `harvestSeconds` และ `add`: เพิ่มพืชของเกมหรือม็อดอื่นที่เก็บแบบเดียวกัน (ต้องมีระยะการโต)
- **regenBlocks**: บล็อกเกิดใหม่แต่ละอัน → `regrowSeconds` และ `harvestSeconds` (แบบคลิกซ้าย)
- **breakRules**: หนึ่งชุดต่อโหนด **กฎการทุบบล็อก** (`_rule` / `_blocks` บอกกฎ) → `add`: เพิ่ม ID บล็อก (หรือ `#แท็ก` ยกเว้น 1.16.5) ที่ใช้กฎเดียวกัน
- เพิ่มได้เฉพาะบล็อกที่มีในเกมหรือม็อดอื่น ID ที่ไม่มีจะถูกข้ามและแจ้งใน log

### ค่าที่บล็อกใช้ร่วมกัน

- มีไอเทมของบล็อกเอง (ปิดสำหรับพืชที่วางด้วยเมล็ด)
- ความแข็ง, ทนระเบิด, เสียงบล็อก, ระดับแสง (0–15)
- ขุดด้วย (อีเต้อ/ขวาน/พลั่ว/จอบ/มือ) และระดับเครื่องมือ
- ต้องใช้เครื่องมือถึงจะดรอป
- จำนวนดรอปต่ำสุด/สูงสุด

### โหนดโมเดล 3D

โหลดไฟล์ `.json` หรือ `.bbmodel` ขา **เท็กซ์เจอร์ #0–#3** จับคู่กับช่องเท็กซ์เจอร์ของโมเดลตามลำดับ โหนดนี้ใช้ได้ทั้งกับไอเทม 3D, บล็อก 3D และเกราะ

## 9. ชุดเกราะ

### ชิ้นเกราะ

ของสวมใส่ 1 ชิ้น ใช้ได้ทันทีโดยไม่ต้องต่ออะไร (ค่าและหน้าตาแบบเหล็ก)

- **ขาเข้า**
  - **วัสดุเกราะ** (ไม่บังคับ)
  - **ไอคอน**
  - **โมเดล 3D**: `.bbmodel`, `.geo.json` หรือโหนดโมเดล 3D ที่เป็นไฟล์ `.json`
  - ขา **เอฟเฟกต์ตอนสวม** ได้สูงสุด 3 ขา
- **ตำแหน่งที่สวม**: หมวก เสื้อ กางเกง หรือรองเท้า
- **ไอคอนไอเทม**:
  - _รูปไอคอน (2D)_ หรือ
  - _โมเดล 3D_: แสดงในช่องเก็บของแบบบล็อก
- **การสวมบนตัวผู้เล่น**
  - ดูตัวอย่าง 3D บนตัว Steve หรือ Alex
  - ปรับ **ตำแหน่ง** (พิกเซล, 16 = 1 บล็อก), **มุมหมุน** (องศา) และ **ขนาด** ติ๊ก **เท่ากันทุกแกน** เพื่อย่อขยายเท่ากันทุกด้าน
  - ลากในช่องตัวอย่างเพื่อหมุนดู กด **รีเซ็ต** เพื่อกลับค่าเดิม
  - เลือกสกิน PNG 64×64 ในโปรเจกต์มาใช้ดูตัวอย่างได้

### วัสดุเกราะ

ค่าที่ใช้ร่วมกันทั้งชุด:

- ตัวคูณความทนทาน และค่าป้องกันของแต่ละชิ้น
- ค่าเอนชานต์, ความแกร่ง, ต้านแรงกระแทก, เสียงตอนสวม, ของที่ใช้ซ่อม
- **เท็กซ์เจอร์ตอนใส่ layer 1** (หมวก เสื้อ รองเท้า) และ **layer 2** (กางเกง) เป็นเท็กซ์เจอร์เกราะ 2D แบบเดียวกับในเกม

### เกราะ 3D

- โหนด **โมเดลเกราะ 3D**: ไฟล์ `.bbmodel` หรือ `.geo.json`
  - เทมเพลตเกราะใช้ bone `armorHead`, `armorBody`, `armorRightArm`/`LeftArm`, `armorRightLeg`/`LeftLeg` และ `armorRightBoot`/`LeftBoot`
  - โมเดลแบบอื่นจะถูกวางบนส่วนของร่างกายตามชิ้นเกราะให้อัตโนมัติ
- โหนด **อนิเมชัน GeckoLib**: ไฟล์ `.animation.json` เลือกอนิเมชันที่จะเล่นวนขณะสวม
- เกราะ 3D ใช้ GeckoLib ซึ่งแอปใส่ให้อัตโนมัติ ใช้ได้กับ 1.20.1 และ 1.21.1 ส่วนเวอร์ชันอื่นจะกลายเป็นเกราะ 2D แทน

## 10. ม็อบและมอนสเตอร์

โหนด **ม็อบ / มอนสเตอร์** (หมวด _ม็อบและมอนสเตอร์_) เพิ่มสิ่งมีชีวิตพร้อมไข่เกิดของมันเอง (ขาออก: ใช้ในแท็บและสูตรคราฟได้)

- **ร่าง**:
  - ร่างจากเกมกับเท็กซ์เจอร์ **สกิน** ของเรา (ทุกเวอร์ชัน): _ซอมบี้_, _โครงกระดูก_, _แมงมุม_ (ดุร้าย), _วัว_, _หมู_ (เป็นมิตร) วาดสกินตามรูปแบบสกินของเกม (จากไฟล์เกมที่ดาวน์โหลดไว้) จะได้พอดี
  - _โมเดล 3D_: โมเดล Blockbench ผ่าน GeckoLib (1.20.1 และ 1.21.1) ต่อโหนด **โมเดลเกราะ 3D (Blockbench)** ที่มีโมเดล เท็กซ์เจอร์ และไฟล์อนิเมชัน เข้าขา **โมเดล 3D** ตั้ง **ความกว้าง / ความสูง hitbox** และชื่ออนิเมชัน **ยืนนิ่ง**, **เดิน**, **โจมตี** (ตามชื่อในไฟล์อนิเมชัน เว้นว่าง = ไม่มี) ในเวอร์ชันอื่นจะใช้ร่างซอมบี้ (หรือร่างหมูถ้าเป็นมิตร) กับ **สกิน** แทน และจะแจ้งในแผง Problems
- **นิสัย** (โมเดล 3D): _ดุร้าย_ โจมตีผู้เล่น, _เฉย ๆ_ สู้กลับเมื่อโดนตี, _เป็นมิตร_ เดินเล่นและวิ่งหนีเมื่อโดนตี ร่างจากเกมใช้นิสัยเดิมของมัน
- **เลือด** (2 = 1 หัวใจ), **พลังโจมตี**, **ความเร็ว**, **เกราะ**
- **เกิดเองตามธรรมชาติใน** โลกปกติ เนเธอร์ หรือดิเอนด์ (1.19.2 ขึ้นไป) ตั้ง **โอกาสเกิด** (ซอมบี้ = 100) และ **จำนวนต่อกลุ่ม** ได้ เวอร์ชันเก่ากว่าใช้ไข่เกิดเท่านั้น
- **ของดรอป**: ได้สูงสุด 3 อย่าง แต่ละอย่างตั้งจำนวนต่ำสุด / สูงสุด
- **สีไข่เกิด**: สีพื้นและสีจุด

## 11. เอฟเฟกต์

โหนด **เอฟเฟกต์** คือเอฟเฟกต์ยา 1 อย่าง (มีให้เลือก 30 แบบ) ต่อเข้า:

- อาหาร → ได้ผลตอนกิน
- เครื่องมือ / อาวุธ → ใส่ศัตรูตอนตี
- ชิ้นเกราะ → ได้ผลตอนสวม (ต่อเวลาให้ตลอด)

ค่าที่ตั้งได้:

- ระดับ (1–1000)
- **ไม่มีวันหมด (∞)** หรือระยะเวลาเป็นวินาที
- โอกาส (0–1)
- แสดงอนุภาค
- แสดงไอคอนสถานะ

### ความสามารถ (ตอนตี / ตอนกิน)

ต่อเข้าขา **ความสามารถตอนตี** ของเครื่องมือ / อาวุธ (เกิดกับเป้าหมายที่ตีโดน) หรือขา **ความสามารถตอนกิน** ของอาหาร (เกิดกับคนที่กิน)

| ความสามารถ | ทำอะไร |
|---|---|
| ติดไฟ | เป้าหมายติดไฟตามระยะเวลา |
| เรียกสายฟ้า | ฟ้าผ่าลงที่เป้าหมาย |
| แช่แข็ง | เป้าหมายหนาวสั่นแบบติดหิมะผง และเดินช้าลง (1.16.5: ได้แค่ความช้า) |
| วาร์ปสุ่ม | วาร์ปไปไกลสูงสุด 8 บล็อก แบบผลคอรัส |
| ล้างเอฟเฟกต์ทั้งหมด | ลบเอฟเฟกต์ทุกอย่าง แบบดื่มนม |

ค่าที่ตั้งได้: ระยะเวลาเป็นวินาที (ติดไฟและแช่แข็ง) และโอกาส (0–1 เช่น 0.25 = ตี 4 ครั้งเกิด 1 ครั้ง)

### โบนัสค่าสถานะ (Attribute)

เปลี่ยนค่าสถานะของผู้เล่นตอนถือ สวม หรือพกไอเทม แบบเดียวกับไอเทมในเกม ต่อเข้าขา **โบนัสค่าสถานะ** ของไอเทม อาหาร เครื่องมือ / อาวุธ หรือชิ้นเกราะ (ขาใหม่จะโผล่ทีละขา สูงสุด 8)

- **ค่าสถานะ**:
  - ทุกเวอร์ชัน: เลือดสูงสุด, เกราะ, ความแกร่งของเกราะ, พลังโจมตี, ความเร็วโจมตี, แรงกระแทกตอนตี, ต้านแรงกระแทก, ความเร็วเดิน, โชค
  - 1.20.4 ขึ้นไป: เลือดเสริมสูงสุด
  - 1.21.1 ขึ้นไป: กระโดดสูง, ระยะขุด/วางบล็อก (ขุดไกล), ระยะตีศัตรู, ความเร็วทุบบล็อก, ขนาดตัว, ก้าวขึ้นที่สูง, แรงโน้มถ่วง, ระยะตกที่ไม่เจ็บ, ตัวคูณความเสียหายจากการตก, ระยะเวลาไฟไหม้, ต้านแรงระเบิด, ประสิทธิภาพการขุด, เดินบนพื้นช้าได้เร็วขึ้น, กลั้นหายใจใต้น้ำนานขึ้น, ความเร็วตอนย่อง, ความเร็วขุดใต้น้ำ, ความเสียหายฟันกวาด, ว่ายน้ำเร็ว
  - ถ้าเวอร์ชันที่เลือกยังไม่มีค่าสถานะนั้น จะถูกข้ามไปพร้อมคำเตือนในแท็บปัญหา
- **ค่า**: ติดลบคือลดลง เลือดสูงสุด: 2 = 1 หัวใจ
- **วิธีคิด**: บวกเพิ่มตามค่า หรือเป็นเปอร์เซ็นต์ของค่าพื้นฐาน / ของค่ารวม (0.5 = +50 %)
- **ทำงานเมื่อ**:
  - _อัตโนมัติ_: เกราะทำงานตอนสวมในช่องของมัน ไอเทมอื่นทำงานตอนถือมือหลัก
  - หรือเลือกเอง: มือหลัก, มือรอง, มือใดก็ได้, ช่องที่สวม (หัว / ลำตัว / ขา / เท้า) หรืออยู่ที่ไหนก็ได้ในช่องเก็บของ
- **แสดงในคำอธิบายไอเทม**: เพิ่มบรรทัดแบบ "เมื่อถือในมือหลัก: +4 เลือดสูงสุด"

## 12. เสียงและแผ่นเพลง

1. โหนด **ไฟล์เสียง**: ไฟล์ `.ogg` 1 ไฟล์
2. โหนด **เสียงในเกม**: เสียงที่เกมเล่นได้
   - ต่อไฟล์เสียงได้ 1–4 ไฟล์ ถ้ามีหลายไฟล์เกมจะสุ่มเล่น
   - ตั้งค่าได้: ID เสียง, คำบรรยาย (EN/ไทย), ความดัง, ระดับเสียง
   - เปิด **สตรีม** สำหรับเพลงยาว
3. โหนด **แผ่นเพลง**: ต่อเสียงในเกมเข้าขา **เพลง** และต่อเท็กซ์เจอร์
   - **ชื่อเพลง** (ศิลปิน - เพลง, EN/ไทย)
   - **ความยาวตามไฟล์เสียง** (อัตโนมัติ) หรือกำหนดเองเป็นวินาที
   - **สถานะลิขสิทธิ์** ที่แสดงบนแผ่น
   - **สัญญาณ Comparator** (1–15)
   - **ระยะการได้ยิน** เป็นบล็อก
   - **เมื่อเพลงจบ**:
     - _ดีดแผ่นออกมาทันที_
     - _เล่นวนซ้ำ (ลูป)_
     - _ค้างอยู่ในเครื่องเล่น_ (แบบปกติของเกม)
     - ดีดออกและลูปใช้ได้เมื่อผู้เล่นใส่แผ่นด้วยมือเท่านั้น ใส่ผ่าน Hopper จะไม่ทำงาน

## 13. สูตรคราฟ

โหนดสูตรคราฟรับขา **วัตถุดิบ** ทางซ้าย และขา **ผลลัพธ์** ทางขวา

| โหนด | วิธีใช้ |
|---|---|
| **คราฟแบบมีรูปแบบ** | ต่อวัตถุดิบได้สูงสุด 9 อย่าง แล้วในแผงคุณสมบัติ **ลากวัตถุดิบไปวางในตาราง 3×3** (หรือคลิกวัตถุดิบแล้วคลิกช่อง) ในตาราง: คลิกช่องเพื่อล้าง, ลากเพื่อย้าย, ลากออกนอกตารางเพื่อลบ ช่องที่ว่างจะว่างในสูตรด้วย ตั้งจำนวนที่ได้ได้ |
| **คราฟแบบไม่มีรูปแบบ** | วัตถุดิบสูงสุด 9 อย่าง วางตรงไหนก็ได้ |
| **เตาเผา / หลอม** | เลือกเตาเผา เตาถลุง เตารมควัน หรือกองไฟ (ใช้กับกระทะของ Farmer's Delight ด้วย) ตั้งค่าประสบการณ์และเวลา (tick, 20 = 1 วินาที) |
| **เครื่องตัดหิน** | วัตถุดิบ 1 อย่าง → ผลลัพธ์ × จำนวน |
| **โต๊ะช่างตีเหล็ก** | แม่แบบ (1.20 ขึ้นไป) + ของตั้งต้น + วัสดุเสริม → ผลลัพธ์ |

วัตถุดิบจะเป็นไอเทมของเราเอง, โหนด **ไอเทมที่มีอยู่แล้ว** หรือ **แท็กไอเทม** ก็ได้

## 14. Farmer's Delight

| โหนด | ค่าที่ตั้งได้ |
|---|---|
| **เขียง** | วัตถุดิบ 1 อย่าง เครื่องมือ: มีด ขวาน อีเต้อ พลั่ว หรือกรรไกร ผลลัพธ์ได้สูงสุด 4 อย่าง แต่ละอย่างตั้งจำนวนและโอกาสได้ |
| **หม้อต้ม** | วัตถุดิบสูงสุด 6 อย่าง, ภาชนะ (เช่น ชาม ไม่บังคับ), ผลลัพธ์และจำนวน, ค่าประสบการณ์, เวลา และหมวดในสมุดสูตร (อาหารจานหลัก/เครื่องดื่ม/อื่น ๆ) |

แอปจะ **ใส่ Farmer's Delight ให้อัตโนมัติ** ตอนทดสอบ ใช้ได้กับ Forge 1.18.2–1.20.1, NeoForge 1.21.1 และ Fabric/Quilt 1.20.1 กับ 1.21.1 ถ้าเป้าหมายอื่น สูตรเหล่านี้จะถูกข้าม และมีคำเตือนในแท็บปัญหา

## 15. แท็บครีเอทีฟ

โหนด **แท็บครีเอทีฟ** สร้างแท็บในหน้าครีเอทีฟ

- **ไอคอน**: ต่อ **เท็กซ์เจอร์โลโก้** หรือ **ไอเทมไอคอน** แทนก็ได้
- ต่อไอเทมเข้าขา **ไอเทม** ทุกครั้งที่ต่อจะมีขาใหม่โผล่ขึ้นมา
- **ลำดับไอเทม** ในแผงคุณสมบัติแสดงของในแท็บ **ลากแถว** เพื่อเรียงใหม่ หรือกด **A→Z / Z→A** เพื่อเรียงตามชื่อ
- ตั้งค่าได้: ID แท็บ, ชื่อแท็บ (EN/ไทย)

ไอเทมที่ไม่ได้ต่อเข้าแท็บไหนเลย จะเป็นไปตามค่าโปรเจกต์ **ไอเทมที่ไม่ได้ต่อแท็บครีเอทีฟ**:

- _ไม่แสดง_: เรียกได้ด้วยคำสั่ง `/give` เท่านั้น
- _ใส่แท็บหลักให้อัตโนมัติ_

## 16. สคริปต์ Java (ขั้นสูง)

โหนด **คลาส Java (สคริปต์)** ใช้เพิ่มไฟล์ Java จริงลงในม็อด เขียนแบบเดียวกับม็อด Minecraft ทั่วไป ใช้กับพฤติกรรมที่โหนดยังทำไม่ได้ ต้องเขียน Java เป็นและรู้ API ของ loader

- **ใช้กับ**: เลือก loader/เวอร์ชันที่ไฟล์นี้เขียนไว้ (ไม่เลือก = ทั้งหมด) API ของ Java ต่างกันในแต่ละ loader/เวอร์ชัน และไฟล์นี้จะไม่ถูกใส่ใน build ของเป้าหมายอื่น
- **ใช้คลาสของม็อดเราได้เลย**: `NkwMod` (มี `MOD_ID`), `ModItems`, `ModBlocks`, `ModSounds`
- **Forge / NeoForge**: ใส่ `@EventBusSubscriber` ที่คลาส และ `@SubscribeEvent` ที่เมธอด event
- **Fabric / Quilt**: `implements ModInitializer` (หรือ `ClientModInitializer`) แล้วแอปจะลงทะเบียน entrypoint ให้
- **ตัวแก้ไขโค้ดใช้งานแบบ IDE**:
  - ไฮไลต์สีและตรวจโค้ดสด
  - มีคำแนะนำระหว่างพิมพ์ คลาสจะถูก **import ให้อัตโนมัติ** กด Ctrl+Space เพื่อขอคำแนะนำ
  - ชี้ที่คลาสเพื่อดู package
  - Ctrl+F ค้นหา
  - ปุ่มขยายเปิดหน้าต่างเขียนโค้ดขนาดใหญ่
- **ใส่โค้ดตัวอย่าง…**: แทนที่โค้ดด้วยคลาสสำเร็จรูปที่เขียนสำหรับ loader/เวอร์ชันที่เลือก
- **ตรวจโค้ด**: คอมไพล์ม็อดด้วย Gradle สำหรับเป้าหมายที่เลือก แล้วขีดเส้นใต้บรรทัดที่ Java error
- บนผืนงาน โหนดจะแสดงชื่อคลาส เป้าหมาย และตัวอย่างโค้ดบรรทัดแรก ๆ
- ชื่อคลาสต้องไม่ซ้ำกับคลาสที่แอปสร้างเอง ถ้าซ้ำจะมีแจ้งในแท็บปัญหา

## 17. ทดสอบในเกมและส่งออก .jar

### ▶ ทดสอบในเกม

1. เลือก **เป้าหมาย** (loader + เวอร์ชัน) ที่แถบบน
2. ดูให้แน่ใจว่าแท็บ **ปัญหา** ไม่มีข้อผิดพลาด
3. กด **▶ ทดสอบในเกม** หรือ Ctrl+Enter แอปจะ:
   - สร้างโปรเจกต์ Gradle สำหรับเป้าหมายนั้น
   - ดาวน์โหลด Java เวอร์ชันที่ถูกต้อง (**ถามก่อน** และตรวจ checksum ทุกไฟล์) และ Gradle
   - เปิด Minecraft พร้อมม็อดของเรา (Fabric/Quilt จะได้ Fabric API และ Mod Menu ด้วย และทุก loader ได้ **AppleSkin** (แสดงค่าความหิว/ความอิ่มของอาหาร) ถ้ามีสำหรับเวอร์ชันนั้น ม็อดเหล่านี้ใช้แค่ตอนทดสอบ ไม่ได้รวมอยู่ในม็อดของเรา)
4. ดูความคืบหน้าได้ใน **คอนโซล** กด **หยุด** เพื่อปิดเกม

> **การทดสอบครั้งแรกของแต่ละเป้าหมายใช้เวลานาน** (หลายนาที และต้องดาวน์โหลด Minecraft กับไลบรารีหลาย GB) ครั้งต่อไปจะเร็วขึ้นมาก

ในเกม หาไอเทมได้ในแท็บครีเอทีฟของเรา หรือใช้คำสั่ง `/give` ที่แสดงในแผงคุณสมบัติ

### ⬇ ส่งออก .jar

กด **⬇ ส่งออก .jar** เมื่อ build เสร็จจะให้เลือกที่บันทึกไฟล์ `.jar` นำไฟล์ไปใส่ในโฟลเดอร์ `mods` ของ Minecraft ที่ใช้ loader ตรงกัน (Fabric/Quilt ต้องมี Fabric API ด้วย และถ้าม็อดใช้ Farmer's Delight หรือ GeckoLib ก็ต้องลงม็อดนั้นด้วย)

ถ้าจะปล่อยหลายเวอร์ชัน ให้สลับ **เป้าหมาย** แล้วส่งออกทีละเป้าหมาย

## 18. ตั้งค่า

เปิดได้จากปุ่มฟันเฟือง

- **ธีม**: ตามระบบ / สว่าง / มืด
- **ภาษา**: ไทย / English
- **หน่วยความจำเกม (RAM)** ตอนทดสอบ: 1–16 GB
- **ดาวน์โหลด Java/Gradle อัตโนมัติเมื่อจำเป็น**
- **Java ที่ติดตั้ง** ที่พบในเครื่อง

แท็บ **เกมตอนทดสอบ** ตั้งค่า Minecraft ที่ใช้ตอน "ทดสอบในเกม" (เขียนลงไฟล์ตั้งค่าของเกมก่อนเปิด ค่าอื่น ๆ คงไว้ตามที่ตั้งในเกม):

- เต็มจอ, ขนาดหน้าต่าง (มีขนาดสำเร็จรูป), FPS สูงสุด (ถึงไม่จำกัด), VSync, ขนาด GUI, ระยะการมองเห็น
- ความดังเสียงหลัก, ความสว่าง, ความไวเมาส์, ภาษาในเกม (ตามแอป, English หรือ ไทย)
- หยุดเกมหรือเล่นต่อเมื่อสลับไปหน้าต่างอื่น
- **ปุ่มควบคุม**: คลิกที่ปุ่ม แล้วกดปุ่มคีย์บอร์ดหรือเมาส์ที่ต้องการ (Esc ยกเลิก) กด **คืนค่าทั้งหมด** เพื่อกลับเป็นปุ่มเดิมของ Minecraft

แท็บ **โปรแกรมทำโมเดล** ตั้งเมาส์และปุ่มของโปรแกรมทำโมเดล: ค่าพื้นฐานแบบ Blockbench, Maya หรือ Blender หรือกำหนดเอง (ดู [โปรแกรมทำโมเดล 3D](#โปรแกรมทำโมเดล-3d))

6. ถ้าต้องการ: เพิ่มโหนด **เอฟเฟกต์** (ความช้า 3 วินาที) แล้วต่อเข้าขา **เอฟเฟกต์ใส่ศัตรูที่ตี 1**
